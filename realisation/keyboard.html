Tastatur-Steuerung

Tastatursteuerungen sind gemäß den Web Content Accessibility Guidelines (WCAG) insbesondere hilfreich für:

  • Menschen mit motorischen Beeinträchtigungen: Diese Nutzer haben möglicherweise Schwierigkeiten, eine Maus präzise zu bewegen, und sind daher auf die Tastatur angewiesen, um auf Webseiten zu navigieren.
  • Sehbehinderte oder blinde Menschen: Diese Nutzer verwenden häufig Screenreader und andere assistive Technologien, die hauptsächlich über die Tastatur gesteuert werden. Eine vollständig per Tastatur steuerbare Webseite ermöglicht es ihnen, Inhalte zu erfassen und zu navigieren. Screenreader bringen selbst eine Tastatursteuerung mit, diese darf durch die Webseite nicht beeinträchtigt werden.
  • Menschen ohne Zugang zu einer Maus: Dies schließt Nutzer ein, die temporär oder situativ keine Maus verwenden können, wie etwa bei bestimmten Geräten oder in bestimmten Umgebungen.

Breadcrumbs - Navigation

Telefonnummer

Telefonnummern können als Link mit hinterlegter Nummer gebaut werden. Eine zusätzliche Tastatursteuerung ist nicht notwendig. Ggf. ist ein erklärender Text hilfreich, der die Funktion "Anrufen" der Enter-Taste beschreibt.

Der Hinweistext ist für alle sichtbar. Er wird über aria-describedby an den Link gebunden. So wird er vorgelesen, wenn der Link aktiv ist. Damit er dann vom Screenreader nicht noch einmal gelesen wird, wird der Absatz selbst mit aria-hidden vom Accessibility Tree ausgeblendet.

<!-- Telefonnummer Beispiel-->
<p>
    Telefonnummer:
    <a 
        href="tel: 0049 221 12 34 56 78-0"
        aria-describedby="phone-description"
    >
        0049 221 12 34 56 78-0
    </a>
</p>
<p id="phone-description" aria-hidden="true"><small>
    Wenn Du die Nummer anklickst oder mit Enter auslöst, wird direkt angerufen. Das geht nur auf dem Mobiltelefon oder wenn auf dem Computer ein Telefon konfiguriert ist.
</small></p>

Die Tastatursteuerung

Pfeiltaste nach rechts

Verschiebt den Fokus eine Zelle nach rechts. Wenn der Fokus auf der äußersten rechten Zelle in der Zeile liegt, verschiebt sich der Fokus nicht.

Pfeiltaste nach links

Verschiebt den Fokus eine Zelle nach links. Wenn der Fokus auf der äußersten linken Zelle in der Zeile liegt, verschiebt sich der Fokus nicht.

Pfeiltaste nach unten

Verschiebt den Fokus eine Zelle nach unten. Wenn der Fokus auf der untersten Zelle in der Spalte liegt, wird der Fokus nicht verschoben.

Pfeiltaste nach oben

Verschiebt den Fokus eine Zelle nach oben. Wenn der Fokus auf der obersten Zelle in der Spalte liegt, verschiebt sich der Fokus nicht.

Taste für Seite nach unten

Der Fokus wird fünf Zeilen nach unten verschoben, wobei ein Bildlauf durchgeführt wird, sodass die unterste Zeile im aktuell sichtbaren Zeilensatz zur ersten sichtbaren Zeile wird.

Wenn der Fokus in der letzten Zeile liegt, verschiebt sich der Fokus nicht.

Taste für Seite nach oben

Der Fokus wird 5 Zeilen nach oben verschoben, wobei so gescrollt wird, dass die oberste Zeile im aktuell sichtbaren Zeilensatz die letzte sichtbare Zeile wird.

Wenn der Fokus in der ersten Zeile des Rasters liegt, verschiebt sich der Fokus nicht.

Pos-1 Taste

verschiebt den Fokus auf die erste Zelle in der Zeile, die den Fokus enthält.

Ende Taste

verschiebt den Fokus auf die letzte Zelle in der Zeile, die den Fokus enthält.

Strg/Ctrl + Pos-1 Taste

verschiebt den Fokus auf die erste Zelle in der ersten Zeile.

Strg/Ctrl + Ende Taste

verschiebt den Fokus auf die letzte Zelle in der letzten Zeile.

verschiebt den Fokus auf die letzte Zelle in der letzten Zeile.

Die Tastatursteuerung der Menüleiste

Leertaste oder Enter

Wenn es sich bei dem Element um ein übergeordnetes Menüelement handelt, wird das Untermenü geöffnet und der Fokus auf das erste Element im Untermenü verschoben.

Andernfalls wird das Menüelement aktiviert, das neuen Inhalt lädt und den Fokus auf die Überschrift setzt, die den Inhalt betitelt.

Pfeiltaste nach rechts

Verschiebt den Fokus auf das nächste Element in der Menüleiste. Wenn der Fokus auf dem letzten Element liegt, wird der Fokus auf das erste Element verschoben.

Pfeiltaste nach links

Verschiebt den Fokus auf das vorherige Element in der Menüleiste. Wenn der Fokus auf dem ersten Element liegt, wird der Fokus auf das letzte Element verschoben.

Pfeiltaste nach unten

Öffnet das Untermenü und verschiebt den Fokus auf das erste Element im Untermenü.

Pfeiltaste nach oben

Öffnet das Untermenü und verschiebt den Fokus zum letzten Element im Untermenü.

Pos-1 Taste

Verschiebt den Fokus auf das erste Element in der Menüleiste.

Ende Taste

Verschiebt den Fokus auf das letzte Element in der Menüleiste.

Eingabe eines Buchstabens

Verschiebt den Fokus auf das nächste Element in der Menüleiste, dessen Name mit dem eingegebenen Zeichen beginnt.

Wenn der Name keines der Elemente mit dem eingegebenen Zeichen beginnt, wird der Fokus nicht verschoben.

Die Tastatursteuerung der Untermenüs

Leertaste oder Enter

Wenn es sich bei dem Element um ein übergeordnetes Menüelement handelt, wird das Untermenü geöffnet und der Fokus auf das erste Element im Untermenü verschoben.

Andernfalls wird das Menüelement aktiviert, das neuen Inhalt lädt und den Fokus auf die Überschrift setzt, die den Inhalt betitelt.

Escape

Schließt das Untermenü.

Verschiebt den Fokus auf das übergeordnete Menüleistenelement.

Pfeiltaste nach rechts

Wenn der Fokus auf einem Element mit einem Untermenü liegt, wird das Untermenü geöffnet und der Fokus auf das erste Element gesetzt.

Wenn der Fokus auf einem Element liegt, das kein Untermenü hat:

  • Schließt das Untermenü.
  • Verschiebt den Fokus zum nächsten Element in der Menüleiste.
  • Öffnet das Untermenü des neu fokussierten Menüleistenelements und behält den Fokus auf dem übergeordneten Menüleistenelement.

Pfeiltaste nach links

Schließt das Untermenü und verschiebt den Fokus zum übergeordneten Menüelement.

Wenn sich das übergeordnete Menüelement in der Menüleiste befindet, gilt außerdem:

  • verschiebt den Fokus zum vorherigen Element in der Menüleiste.
  • Öffnet das Untermenü des neu fokussierten Menüleistenelements und behält den Fokus auf dem übergeordneten Menüleistenelement.

Pfeiltaste nach unten

Verschiebt den Fokus auf das nächste Element im Untermenü.

Wenn der Fokus auf dem letzten Element liegt, wird der Fokus auf das erste Element verschoben.

Pfeiltaste nach oben

Verschiebt den Fokus zum vorherigen Element im Untermenü.

Wenn der Fokus auf dem ersten Element liegt, wird der Fokus auf das letzte Element verschoben.

Pos-1 Taste

Verschiebt den Fokus auf das erste Element im Untermenü.

Ende Taste

Verschiebt den Fokus auf das letzte Element im Untermenü.

Eingabe eines Buchstabens

erschiebt den Fokus auf das nächste Element, dessen Name mit dem eingegebenen Zeichen beginnt.

Wenn der Name keines der Elemente mit dem eingegebenen Zeichen beginnt, wird der Fokus nicht verschoben.

Tastatursteuerung für Tabellen der verschiedenen Screenreader

Wenn man Tastatursteuerungen mittels Javascript einfügt, sollte man die vorhandenen Tastenkürzel der Screenreader nicht aushebeln!

NVDA

Befehl Tasten-Kombination
Zur nächsten/vorherigen Tabelle auf der Seite t / Shift + t
Zur nächsten/vorherigen Zelle in einer Zeile Ctrl + Alt + Pfeil nach rechts/links
Zur nächsten/vorherigen Zelle in einer Spalte Ctrl + Alt + Pfeil nach unten/oben

JAWS

Befehl Tasten-Kombination
Zur nächsten/vorherigen Tabelle auf der Seite t / Shift + t
Zur nächsten/vorherigen Zelle in einer Zeile Ctrl + Alt + Pfeil nach rechts/links
Zur nächsten/vorherigen Zelle in einer Spalte Ctrl + Alt + Pfeil nach unten/oben
Alle Tabellen listen JAWS + Ctrl + T

Narrator

Befehl Tasten-Kombination
Zur nächsten/vorherigen Tabelle auf der Seite t / Shift + t (nur im Scan-Modus)
Zur nächsten/vorherigen Zelle in einer Zeile Ctrl + Alt + Pfeil nach rechts/links
Zur nächsten/vorherigen Zelle in einer Spalte Ctrl + Alt + Pfeil nach unten/oben
Alle Tabellen listen Aufruf über Views (s. o.)

VoiceOver

Befehl Tasten-Kombination
Zur nächsten/vorherigen Tabelle auf der Seite VO + Command + t
Zur nächsten/vorherigen Zelle in einer Zeile VO + Pfeil nach rechts/links
Zur nächsten/vorherigen Zelle in einer Spalte VO + Pfeil nach unten/oben
Alle Tabellen auflisten VO + u (Aufruf Rotor-Inhalte) und Navigation mit Pfeil nach rechts/links zu Tabellen (dann Auswahl mit Pfeiltasten nach oben/unten und Bestätigung mit Enter)
